# Tianyu Zhou — Academic Homepage

A lightweight, static academic homepage designed for GitHub Pages. It follows the clean, minimal structure of the reference page while using Tianyu Zhou's own CV content and portrait.

## Files

- `index.html` — all website content
- `assets/css/style.css` — styling and responsive layout
- `assets/img/profile.jpg` — profile photo
- `assets/img/favicon.svg` — favicon
- `assets/files/Tianyu_Zhou_CV.docx` — downloadable CV
- `.nojekyll` — serves the static files directly on GitHub Pages

## Deploy to GitHub Pages

### Option A: personal homepage
1. Create a GitHub repository named `<your-github-username>.github.io`.
2. Upload everything in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Your site will be available at `https://<your-github-username>.github.io/`.

### Option B: project homepage
1. Create any repository, for example `homepage`.
2. Upload these files to the repository root.
3. Enable GitHub Pages from the `main` branch and `/ (root)`.
4. The site will be available at `https://<your-github-username>.github.io/homepage/`.

## Recommended edits before publishing

Open `index.html` and update or add:
- GitHub profile URL
- Google Scholar URL (once available)
- LinkedIn / ORCID if desired
- Publication DOI / arXiv / project links when available

The public page intentionally omits the phone number from the CV.
